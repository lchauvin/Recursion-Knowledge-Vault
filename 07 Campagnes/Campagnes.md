# Campagnes

Chaque campagne a son propre dossier, créé à partir du dossier `_Modele de campagne`. Ce qui se passe dans une campagne reste local tant qu'il n'est pas validé dans la [[Chronique du monde]].

## Créer une campagne

1. Copier le dossier `_Modele de campagne` et le renommer, par exemple `2026 - Les voleurs de dormeurs`.
2. Remplir la page `Campagne` : groupe, date de départ dans le monde (en AR), lieu de départ.
3. Créer une fiche par personnage joueur avec le modèle [[Personnage joueur]].
4. Après chaque séance, ajouter une page avec le modèle [[Seance|Séance]].

## Fin de campagne

1. Relire le journal et lister ce qui a changé dans le monde.
2. Choisir ce qui devient canon, et l'ajouter à la [[Chronique du monde]].
3. Mettre à jour les pages concernées : personnages non joueurs, lieux, factions.
4. Les personnages joueurs peuvent devenir des personnages non joueurs, ou des légendes, pour les groupes suivants.
