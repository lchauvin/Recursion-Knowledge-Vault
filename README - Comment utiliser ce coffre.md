# Comment utiliser ce coffre

Ce coffre contient tout le jeu : l'univers, les règles, le scénario d'introduction, et la place pour vos campagnes. Il est pensé pour faire vivre un monde persistant, où chaque campagne peut laisser des traces pour les suivantes.

## Ouvrir le coffre

1. Installer [Obsidian](https://obsidian.md), gratuit.
2. Dans Obsidian, choisir « Ouvrir un dossier comme coffre » et sélectionner le dossier `Recursion`.
3. Dans les réglages, activer le module **Modèles** et choisir le dossier `Modeles` comme emplacement des modèles.

## Comment le coffre est organisé

- **01 Le jeu** : le pitch, les inspirations, le thème de l'identité.
- **02 Univers** : la chronologie, les factions, les peuples, les lieux.
- **03 Regles** : une page par règle.
- **04 PNJ** : une fiche par personnage non joueur.
- **05 Scenarios** : les scénarios prêts à jouer.
- **06 Joueurs** : ce que les joueurs peuvent lire, sans les secrets du MJ.
- **07 Campagnes** : un dossier par campagne.
- **Chronique du monde** : ce que les campagnes ont rendu vrai pour tout le monde.
- **Modeles** : des pages vierges pour une séance, un personnage non joueur, un lieu, une Ruche, un personnage joueur, une faction ou un événement.

## Les secrets

Chaque page indique sa visibilité dans ses métadonnées : `mj` ou `joueurs`. Les secrets sont aussi placés dans des encadrés repliés « Réservé au MJ ». Pour partager le coffre avec vos joueurs un jour, il suffira de leur donner les pages marquées `joueurs`.

## Avec un assistant IA

Le fichier `CLAUDE.md` explique à un assistant comment utiliser le coffre : tenir le journal des séances, répondre aux questions de règles en citant ses sources, protéger les secrets et proposer ce qui peut devenir canon. Claude Code le lit automatiquement quand on ouvre ce dossier ; avec un autre assistant, il suffit de lui demander de le lire en premier.
